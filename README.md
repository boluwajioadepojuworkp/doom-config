# Doom Emacs Configuration

**By Boluwaji Oluwaseyi Adepoju**

Personal Doom Emacs configuration optimized for Computer Science coursework, note-taking with Org-Roam, and academic writing with LaTeX.

## Features

- Org-Roam note-taking with Zettelkasten workflow
- LaTeX editing with AUCTeX, CDLaTeX, Xenops
- Python development environment
- Full knowledge management stack

## Key Modules

- `:lang org` + `+roam2` — Note-taking and knowledge management
- `:lang latex` + `+cdlatex` + `+latexmk` — Academic writing
- `:lang python` — Programming and data science
- `:tools lsp` — Language server support

## Setup

```bash
git clone https://github.com/boluwajioadepojuworkp/doom-config ~/.doom.d
```
